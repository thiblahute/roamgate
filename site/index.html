Get started

One line, then log in.

  1. Run the line for your system. It checks the release's checksum and installs roamgate.
  2. Run roamgate and keep it running.
  3. In another terminal, roamgate url prints the login link, http://localhost:8787/?token=.... Open it: the token in it logs you in.

Roamgate needs a running Herdr; roamgate herdr setup installs and starts it.

The Work board

Know what waits on you.

Every piece of work in one board: For you, Doing, Verify, Open, and Done. Agents add and move the items they work on, and the ones that need your decision say exactly what to do, with answers you can tap.

  • Design docs you can comment on

    An item's description reads as a document. Comment on any paragraph, list item, or table cell; the agent asks its open questions there and writes your answers back in.

  • Owned by the agent doing it

    Each card names the session working on it. Open the agent's work in one click, and your comments on the item reach it.

  • Fast by keyboard or touch

    Drag cards between columns, filter by words, tags, or owner, and drive it all with Vim-style keys. Projects and their subprojects share one board.

Meet Ranger

Talk through your workspace.

Ranger is an experimental workspace management assistant. Ask about workspace status, agent history, and diffs; let it create workspaces, worktrees, and tabs, arrange the Workspaces tree, and schedule background checks. Connect a model provider or use Claude Code. Keep Herdr and the Roamgate bridge running.

Agents as conversations

Every agent, as a chat.

Any agent pane can show its conversation as a chat while its terminal keeps running underneath. Questions become buttons, permission prompts become cards, and sessions on every connection can message each other.

Chat or terminal, per pane

Read and answer an agent as a chat, with its questions as buttons, Allow, Always, or Deny on its permission prompts, and a message that tells you when it was delivered.

Conversation mode for Claude Code

Hand a Claude Code session to a headless Claude that the chat drives, and back to its terminal at any time. Works on local and SSH hosts running Linux or macOS.

Agents messaging agents

Sessions list each other and send messages across every connection. The receiver knows it comes from another agent, not from you, and a rate limit keeps them from looping.

Resume after a usage limit

A Claude session stopped by its usage limit shows when it resumes, and Roamgate wakes it once the limit resets. Agent profiles start sessions with other accounts or settings.

Experimental: voice

Call your agents. Dictate anywhere.

Speak hands-free with an agent from your phone, a headset, or the car: it hears you, sends what you said once you pause, and reads the answer aloud in its language. Voice needs Roamgate's voice helper, built from source on macOS or Linux; reading replies aloud with the browser's voices needs no setup.

  • Hands-free calls

    Talk over a reply to cut it, mute without hanging up, and keep the call through network changes. Saying "stop" ends it.

  • Dictation in every text box

    The microphone types cleaned text where the cursor is: fillers and false starts gone, spoken punctuation written.

  • Reaches every session

    Ask for another session by what it is about and the call switches to it. Questions about your sessions go to Ranger.

From daemon to dashboard

Running in three steps.

Roamgate is a thin bridge around the runtime you already use. Your agents still live in real terminal sessions owned by Herdr.

  1. 1

    Herdr keeps agents alive

    Start the coding agents you already use. Herdr owns their terminal sessions, even when your browser or laptop disconnects.

  2. 2

    Roamgate connects locally or over SSH

    Run one native binary beside Herdr, with nothing else to install. It bridges the local socket API, terminal stream, files, Git operations, and session records.

  3. 3

    Your browser becomes the cockpit

    Open the printed URL from desktop or mobile. Install it as a PWA for a focused, app-like control surface.

Now native

Rewritten in Rust. Nothing else to learn.

Roamgate's server is now one native roamgate binary written in Rust, with the web app built in. Same features, same commands, and the same files on disk: update and carry on.

  • One binary, no runtime

    The server, its core, and the web app ship in a single executable, with the Ranger model helper bundled beside it. There is no Bun or Node runtime to install; the installer and roamgate update work as before.

  • Your data, as it is

    Settings, connections, reviews, the Work board, and history are read from the same files, in place. Nothing to migrate or export.

  • A faster terminal

    Terminal output reaches the browser with lower latency than the previous server at the same frame rate.

Ranger's models other than Claude Code run through a bundled roamgate-pi helper that ships in the same archive, and voice stays an optional helper you build when you want it.
