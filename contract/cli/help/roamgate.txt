Roamgate — Web and PWA client for Herdr

Usage: roamgate [options]              run the server
       roamgate <command> [arguments]  manage an installation

Commands:
  service      install and manage the Roamgate user service
  herdr        install, start and check the local Herdr server
  setup        set up voice chat: detect the hardware, download its models
  voice        voice profiles: the low-GPU set while a game runs
  doctor       diagnose the installation and suggest fixes
  url          print login URLs, optionally as a QR code
  config       show or change the service configuration
  auth         show or rotate login credentials and sign out browsers
  connections  list, test and edit Herdr connection profiles
  push         send a test Web Push notification to enrolled devices
  activity     read the activity log: day summaries, events, status
  reviews      export or import the Reviews' order, overrides, views, efforts
  history      show or commit the local history of what was authored
  archive      archive and search Claude Code, Codex and Pi sessions
  update       update roamgate to the latest release
  rollback     restore the executable replaced by the last update
  plugin       actions and panel used by the Herdr plugin
  completion   print a bash, zsh or fish completion script

Run `roamgate <command> --help` or `roamgate help <command>` for details.

Options (flags override env vars; ROAMGATE_* overrides HERDR_GUI_*):
  --host <addr>              listen address        (env HOST,            default 127.0.0.1)
  --port <n>                 listen port           (env PORT,            default 8787)
  --password <pw>            fixed login password, 8..1024 characters
                             (env ROAMGATE_PASSWORD; otherwise a token is generated)
  (env ROAMGATE_PIN)         optional 6..12 digit convenience login; private networks only
  --tls-cert <path>          PEM certificate chain (env ROAMGATE_TLS_CERT; requires --tls-key)
  --tls-key <path>           PEM private key       (env ROAMGATE_TLS_KEY; requires --tls-cert)
  --socket-path <path>       control socket        (env HERDR_SOCKET_PATH)
  --client-socket-path <p>   render socket         (env HERDR_CLIENT_SOCKET_PATH)
  --ssh-host <user@host>     remote Herdr over SSH (env HERDR_SSH_HOST)
  --session <name>           named herdr session   (env HERDR_SESSION)
  --public-dir <path>        static assets dir     (env PUBLIC_DIR,      default: embedded)
  --log-level <level>        error|warn|info|debug  (env ROAMGATE_LOG_LEVEL, default: info)
  --notification-source <s>  herdr|status: task alerts follow Herdr notifications or
                             Roamgate's own status tracker (env ROAMGATE_NOTIFICATION_SOURCE, default: herdr)
  --profile                  capture server CPU samples (env ROAMGATE_PROFILE=1)
  --profile-duration <secs>   capture for 1..300 seconds (env ROAMGATE_PROFILE_DURATION, default: 30)
  --profile-dir <path>        output parent directory (env ROAMGATE_PROFILE_DIR, default: Roamgate data dir/profiles)
  --open                     open browser on start (env OPEN_BROWSER=1)
  -V, --version              show version
  -h, --help                 show this help
