# Environment variables

Every variable the server reads, with the source files under `crates/`
that name it. `ROAMGATE_<X>` takes precedence over `HERDR_GUI_<X>`,
including an explicitly empty value; flags of the server override both.
The parity suite's gate (`parity/tests/gate.rs`) checks the table against
the crates: every name it lists is read there, and every `ROAMGATE_` or
`HERDR_GUI_` variable they read is listed.
